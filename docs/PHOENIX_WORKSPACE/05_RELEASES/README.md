# PHOENIX RELEASES

## Overview

Questa directory contiene la cronologia ufficiale delle release della Phoenix Workspace e del progetto.

Ogni documento di release rappresenta una fotografia dello stato del progetto in un determinato momento.

Le release non sostituiscono il Master Record.

Il Master Record descrive l'evoluzione continua del progetto.

Le Release documentano invece il completamento di una milestone significativa.
