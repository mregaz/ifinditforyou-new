# IFINDITFORYOU ATLAS TO GROWTH STRATEGY v1.0

## 1. Role

PHOENIX ATLAS should be a **private market map and public-content opportunity engine**, not a document dump.

Atlas can help identify:

- which marketplaces exist by country and vertical;
- which sources are generalist vs specialist;
- known access/governance boundaries;
- fragmented search journeys;
- source gaps worth researching;
- public questions that can be answered with new, separately authored material.

It must not automatically publish internal artifacts, provider tactics, restricted data, security details, proprietary source-resolution logic or uncertified inferences.

## 2. Publication decision gate

Every Atlas-derived public asset must pass:

```text
source permission known
→ no confidential/internal-only content
→ no security/access circumvention detail
→ facts independently re-verified at publication time
→ public artifact has new identity and author
→ sources, date, scope and limitations visible
→ no claim of universal completeness
```

If permission, currency or provenance is unknown: do not publish.

### Publication accountability

Eligibility is not publication authorization. Every governed public Growth artifact must have an accountable **Owner**, **Author**, **Reviewer**, verification date where freshness matters, source record, scope, limitations, refresh policy, and correction/withdrawal authority.

Canonical publication states are `DRAFT`, `REVIEWED`, `PUBLISHED`, `STALE`, and `WITHDRAWN`. Material errors require correction or withdrawal. Stale material must not continue to be represented as currently verified fact. User activity does not imply publication consent. AI drafting does not replace verification, and programmatic generation does not imply programmatic publication.

Operational lifecycle governance is owned by `GROWTH/README.md`.

## 3. Public-safe product ladder

### Level 1 — Editorial guides

- Where to look for a used Vespa in Switzerland.
- Swiss marketplaces for vintage motorcycle parts.
- General vs specialist sources for used photography gear.
- What changes when searching across German-, French- and Italian-speaking regions.

These are human-reviewed, source-linked and easy to retract/update.

### Level 2 — Marketplace directory

Public fields only:

```text
marketplace name
public URL
country/region
public category coverage
generalist/specialist
publicly documented access mode
last verified date
source citation
explicit unknowns
```

Do not expose internal provider priority, unannounced integration status, credentials, failure tactics or competitive assessments.

### Level 3 — Comparison pages

Examples:

- MotoScout24 vs Ricardo vs Tutti for used scooters: scope and workflow, not “winner”.
- Which source types surface rare parts?
- What “coverage” means and does not mean.

### Level 4 — Market reports

- quarterly supply snapshots from legally/publicly usable aggregate data;
- source fragmentation index;
- search difficulty by category;
- unavailable/unknown coverage explicitly reported.

### Level 5 — Searchable directory/programmatic layer

Only after:

- stable public schema;
- permission review;
- editorial quality floor;
- deduplication;
- update lifecycle;
- canonical URLs;
- proof that pages answer distinct user needs.

## 4. Content flywheel

```text
Atlas opportunity map
→ user search need
→ permitted sources checked
→ verified result/coverage gap
→ human-reviewed insight
→ public-safe case study or guide
→ SEO/community/partner discovery
→ new user search
→ new evidence about demand
```

The public asset is downstream content with separate identity and provenance. It never becomes Atlas canonical truth merely because it performed well in search.

## 6. GEO/AEO format

For each public page:

1. one-sentence direct answer;
2. `Last verified` date;
3. scope and country;
4. structured table of public facts;
5. methodology;
6. limitations/unknowns;
7. citations to primary public sources;
8. named author/reviewer;
9. changelog;
10. machine-readable structured data only when it matches visible content.

Google’s official 2026 guidance says useful unique content and normal SEO foundations remain central to generative search; no special markup guarantees AI citation ([Google Search Central](https://developers.google.com/search/blog/2026/05/a-new-resource-for-optimizing), evidence **A**).

## 7. Atlas growth opportunity score

Score candidate content 0–2 on each:

```text
real user demand
source fragmentation
public-source availability
publication permission clarity
unique insight
refreshability
conversion relevance
competitive difficulty
```

Publish only if:

- permission clarity = 2;
- public-source availability = 2;
- total ≥12/16;
- named owner accepts refresh duty.
