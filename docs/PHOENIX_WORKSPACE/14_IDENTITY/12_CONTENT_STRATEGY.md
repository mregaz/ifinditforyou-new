# 1. Purpose

## 1.1 Objective

This document defines the content strategy of Phoenix.

Its objective is to ensure that every piece of content published by Phoenix is useful, consistent, trustworthy and aligned with the project's identity.

Content should educate, inform and assist users.

It should never exist simply to increase volume.

---

# 2. Scope

This strategy applies to:

- Website
- Landing Pages
- Documentation
- Help Center
- FAQ
- Blog
- Email Communication
- Product Descriptions
- Notifications
- AI-generated Content
- Marketing Material

# 4. Content Philosophy

Every piece of content should create value.

Content is part of the product.

Users should leave every page with a better understanding than when they arrived.

Quality always comes before quantity.

Clarity always comes before creativity.

Trust always comes before persuasion.

---

# 5. Content Principles

## 5.1 Useful

Every page should solve a real question or problem.

If content provides no value, it should not exist.

---

## 5.2 Clear

Use simple language.

Avoid unnecessary technical jargon.

Explain concepts progressively.

---

## 5.3 Accurate

Information should be verified before publication.

Incorrect content damages trust.

---

## 5.4 Consistent

Terminology should remain consistent across the entire platform.

The same concept should always use the same wording.

---

## 5.5 Evergreen

Whenever possible, create content that remains useful over time.

Avoid unnecessary references that quickly become outdated.

---

## 5.6 Actionable

Readers should know what to do after reading.

Every important page should help users take the next logical step.

---

Each category should follow the same quality principles.

---

# 7. Writing Standards

Every content creator should:

- Write clearly
- Prefer short paragraphs
- Use descriptive headings
- Structure information logically
- Eliminate redundancy
- Review grammar
- Verify facts before publishing

Avoid:

- Clickbait
- Exaggerated claims
- Ambiguous wording
- Keyword stuffing

---

# 8. SEO Principles

Search engine optimization should improve discoverability without reducing readability.

SEO should support users.

Never manipulate search engines at the expense of content quality.

Priority order:

1. User Value
2. Readability
3. Accuracy
4. Search Optimization

---

# 9. AI Generated Content

Artificial Intelligence may assist content creation.

However:

- Humans remain responsible for accuracy.
- AI-generated content should always be reviewed.
- AI should improve productivity, not replace editorial judgment.
- Transparency should be maintained whenever appropriate.

AI is an assistant.

Not an author.

---

# 10. Content Governance

Before publishing, every content should be reviewed against the following checklist.

- □ Is it useful?
- □ Is it accurate?
- □ Is it understandable?
- □ Is it aligned with Phoenix Values?
- □ Does it maintain trust?
- □ Is it consistent with existing content?
- □ Does it respect the Communication Guidelines?

If multiple answers are "No", publication should be postponed.
