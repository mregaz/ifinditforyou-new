# 1. Purpose

## 1.1 Objective

This document defines the visual identity of Phoenix.

Its purpose is to ensure that every visual element communicates consistency, professionalism and trust across every platform.

Visual identity is not decoration.

It is part of the user experience.

---

# 2. Scope

This document applies to:

- Website
- Dashboard
- Finder
- Mobile applications
- Documentation
- Marketing material
- Presentations
- Social media
- Email templates
- Product screenshots

---

# 3. Does NOT Cover

This document does not define:

- UX behavior
- Content strategy
- Brand messaging
- Technical implementation

These subjects are documented separately.

---

# 4. Design Philosophy

Phoenix follows a minimalist visual philosophy.

Every visual element should support usability before aesthetics.

Good design should reduce cognitive load.

Users should immediately understand where they are, what they can do and what information matters.

Visual consistency builds trust.

---

# 5. Visual Principles

Every interface should be:

- Clean
- Consistent
- Modern
- Accessible
- Readable
- Professional
- Calm
- Focused on content

Avoid unnecessary visual effects.

Avoid decorative elements without purpose.

Every design decision should improve clarity.

---

# 6. Logo

The Phoenix logo represents reliability, rebirth and continuous evolution.

The logo should always:

- remain readable
- preserve its proportions
- maintain sufficient clear space
- be used consistently

The logo should never:

- be stretched
- be rotated
- use unofficial colors
- include effects or shadows
- be modified without approval

---

# 7. Color System

The color palette should communicate:

Primary colors

- Trust
- Professionalism
- Simplicity

Secondary colors

- Support hierarchy
- Differentiate interface elements

Status colors

- Success
- Warning
- Error
- Information

Colors should never become the only way to communicate information.

Text, icons or labels should always provide additional meaning.

---

# 8. Typography

Typography should prioritize readability.

Recommended principles:

- Limited number of font families
- Clear hierarchy
- Consistent spacing
- Comfortable line height

Avoid decorative fonts.

Typography should remain functional across all devices.

---

# 9. Icons & Illustrations

Icons should:

- communicate meaning instantly
- remain visually consistent
- use a unified style
- support navigation

Illustrations should simplify understanding.

They should never distract from the product.

---

# 10. Photography & Images

Images should communicate:

- authenticity
- quality
- clarity
- professionalism

Avoid:

- generic stock photography
- misleading imagery
- excessive visual effects

Whenever possible, prefer real product screenshots over promotional graphics.

---

# 11. User Interface Consistency

All interfaces should share:

- consistent spacing
- consistent navigation
- consistent buttons
- consistent colors
- consistent typography
- consistent terminology

Users should immediately recognize they are using Phoenix.

---

# 12. Accessibility

Visual design should remain accessible.

Interfaces should consider:

- sufficient color contrast
- readable font sizes
- keyboard navigation
- scalable layouts
- responsive design

Accessibility improves usability for everyone.
